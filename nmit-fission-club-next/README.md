# FISSION NMIT — Next.js

Next.js conversion of the FISSION Club static website.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Build for production

```bash
npm run build
npm start
```

The original visual styling is kept in `app/globals.css`. Client-side interactions from the original `script.js` are implemented in `app/page.tsx`.
